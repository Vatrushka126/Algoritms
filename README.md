## A. Сортировка выбором

Дан список целых чисел. Выведите все элементы этого списка в порядке невозрастания значений. Выведите новый список на экран.

Решите эту задачу при помощи алгоритма сортировки выбором. Решение оформите в виде функции SelectionSort(A).

В алгоритме сортировки выбором мы находим наибольший элемент в списке и ставим его на первое место, затем находим наибольший элемент из оставшихся и ставим его на второе место и т. д.

### Пример

Входные данные:

1 4 2 3 4

Выходные данные:

4 4 3 2 1

## B. Сортировка вставкой

Дан список целых чисел. Отсортируйте его в порядке неубывания значений. Выведите полученный список на экран.

Решите эту задачу при помощи алгоритма сортировки вставкой. Решение оформите в виде функции InsertionSort(A).

В этой задаче нельзя пользоваться дополнительным списком, операциями удаления и вставки элементов.

В алгоритме сортировки вставкой в каждый произвольный момент начальная часть массива уже отсортирована. В решении имеется цикл for i in range(1, len(A)).

Внутри предполагается, что элементы списка A[0], A[1], ..., A[i-1] уже отсортированы, а элемент A[i] добавляется в отсортированную часть списка.

Для этого находится позиция, в которую необходимо вставить элемент A[i], затем осуществляется циклический сдвиг фрагмента уже отсортированной части.

### Пример

Входные данные:

1 4 2 3 4

Выходные данные:

1 2 3 4 4

## C. Сортировка пузырьком

Дан список целых чисел. Отсортируйте его в порядке невозрастания значений. Выведите полученный список на экран.

Решите эту задачу при помощи алгоритма пузырьковой сортировки. Решение оформите в виде функции BubbleSort(A).

В алгоритме пузырьковой сортировки осуществляется проход по списку от начала к концу, и если два соседних элемента списка стоят в неверном порядке, то они переставляются в правильном порядке. В результате минимальный элемент массива окажется на последнем месте. Повторим эту процедуру еще несколько раз, чтобы поставить все элементы на свои места.

Вспомогательным списком пользоваться нельзя.

### Пример

Входные данные:

1 4 2 3 4

Выходные данные:

4 4 3 2 1

## H. Гоблины Мглистых гор

Гоблины часто приходят к шаманам, из-за чего образуются длинные очереди. Обычные гоблины встают в конец очереди. Привилегированные гоблины, знающие особый пароль, встают в середину очереди. Если длина очереди нечётная, они встают сразу за центром.

Необходимо написать программу, которая отслеживает порядок гоблинов в очереди.

**Входные данные**

В первой строке записано число `N` — количество запросов к программе.

Следующие `N` строк содержат команды трёх типов:

- `+ i` — гоблин с номером `i` встаёт в конец очереди.
- `* i` — привилегированный гоблин с номером `i` встаёт в середину очереди.
- `-` — первый гоблин уходит к шаману.

Гарантируется, что при запросе `-` очередь не пуста.

**Выходные данные**

Для каждого запроса `-` выведите номер гоблина, который отправляется к шаману.

### Пример

Входные данные:

```text
7
+ 1
+ 2
* 3
-
+ 4
* 5
-
```

Выходные данные:

```text
1
2
```
