# Бинарное дерево

## A. Бинарное дерево (вставка, поиск, удаление)

Реализуйте бинарное дерево поиска, поддерживающее операции вставки,
удаления и поиска элементов по значению.

Программа должна обрабатывать запросы следующих видов:

-   `ADD n` --- если числа `n` ещё нет в дереве, добавить его и вывести
    `DONE`. Если число уже есть, дерево не изменять и вывести `ALREADY`.
-   `DELETE n` --- если число `n` есть в дереве, удалить его и вывести
    `DONE`. Если числа нет, дерево не изменять и вывести `CANNOT`. При
    удалении вершины с двумя детьми необходимо обменять её значение с
    максимальным элементом левого поддерева.
-   `SEARCH n` --- вывести `YES`, если число найдено в дереве, иначе
    вывести `NO`. Дерево при этом не изменяется.
-   `PRINTTREE` --- вывести всё дерево по заданному алгоритму.

### Входные данные

В каждой строке записан один из запросов `ADD n`, `DELETE n`, `SEARCH n`
или `PRINTTREE`.

Гарантируется, что запросы `PRINTTREE` будут вызываться только тогда,
когда дерево не пустое. Общее количество запросов не превышает 1000, из
них не более 20 запросов `PRINTTREE`.

### Выходные данные

Для запросов `ADD`, `DELETE` и `SEARCH` выведите соответствующее слово в
отдельной строке.

Для запроса `PRINTTREE` выведите дерево следующим образом: сначала левое
поддерево, затем значение текущей вершины с отступом из точек по числу
уровней, затем правое поддерево. Изначальный вызов алгоритма ---
`print_tree(root, 0)`.

## K. Следующий

Реализуйте структуру данных, поддерживающую множество `S` целых чисел и
следующие операции:

-   `add(i)` --- добавить число `i` в множество `S`. Если число уже
    присутствует, множество не изменяется.
-   `next(i)` --- вывести минимальный элемент множества, не меньший `i`.
    Если такого элемента нет, вывести `-1`.

### Входные данные

Изначально множество `S` пусто.

В первой строке задано число `n` --- количество операций
(`1 ≤ n ≤ 300 000`). Следующие `n` строк содержат операции одного из
двух видов:

-   `+ i` --- операция добавления числа;
-   `? i` --- запрос `next(i)`.

Если операция `+ i` находится в начале входных данных или следует после
другой операции `+`, выполняется обычное добавление `i`.

Если операция `+ i` следует после запроса `?`, ответом на который было
`y`, вместо `i` добавляется число `(i + y) mod 10^9`.

Во всех запросах и операциях добавления параметры находятся в диапазоне
от `0` до `10^9`.

### Выходные данные

Для каждого запроса `?` выведите одно число --- результат операции
`next(i)`.
