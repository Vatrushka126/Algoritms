## A. Задача №755. Хипуй!

В этой задаче необходимо организовать структуру данных `Heap` для хранения целых чисел, над которой определены следующие операции:

- `Insert(k)` — добавить в кучу число `k` (`1 ≤ k ≤ 1 000 000`).
- `Extract` — достать из кучи наибольшее число, удалив его.

### Входные данные

В первой строке содержится количество команд `N` (`1 ≤ N ≤ 100 000`), далее следуют `N` команд, каждая в своей строке.

Команда может иметь один из двух форматов:

- `0 <число>` — операция `Insert(<число>)`;
- `1` — операция `Extract`.

Гарантируется, что при выполнении команды `Extract` в структуре находится хотя бы один элемент.

### Выходные данные

Для каждой команды извлечения необходимо отдельной строкой вывести число, полученное при выполнении команды `Extract`.

### Пример

Входные данные:

```text
2
0 10000
1
```

Выходные данные:

```text
10000
```

## C. Задача №3493. Пирамида (минимум)

Задача отличается от задачи «Пирамида (максимум)» исключительно тем, что надо извлекать не максимум, а минимум.

Напишите программу, которая будет обрабатывать последовательность запросов следующих видов:

- `CLEAR` — сделать пирамиду пустой (если в пирамиде уже были какие-то элементы, удалить все). Действие происходит только с данными в памяти, на экран ничего не выводится.
- `ADD n` — добавить в пирамиду число `n`. Действие происходит только с данными в памяти, на экран ничего не выводится.
- `EXTRACT` — вынуть из пирамиды минимальное значение. Следует изменить данные в памяти и вывести найденное минимальное значение. Если пирамида была пустой, вывести слово `CANNOT` (большими буквами).

### Входные данные

Во входных данных записана произвольная последовательность запросов `CLEAR`, `ADD` и `EXTRACT` — каждый в отдельной строке, согласно описанному формату.

Суммарное количество всех запросов не превышает 200 000.

### Выходные данные

Для каждого запроса типа `EXTRACT` выведите на стандартный выход результат в отдельной строке.

## E. Задача №746. Коммерческий калькулятор

Фирма OISAC выпустила новую версию калькулятора. Этот калькулятор берёт с пользователя деньги за совершаемые арифметические операции. Стоимость каждой операции в долларах равна 5% от числа, которое является результатом операции.

На этом калькуляторе требуется вычислить сумму `N` натуральных чисел. Нетрудно заметить, что от того, в каком порядке мы будем складывать эти числа, зависит стоимость вычисления суммы.

Например, пусть нужно сложить числа 10, 11, 12 и 13. Если сначала сложить 10 и 11, затем результат с 12, а после этого с 13, общая стоимость будет 5.00. Если сначала отдельно сложить 10 и 11, затем 12 и 13, а после этого сложить два полученных результата, общая стоимость составит 4.60.

Напишите программу, которая определит минимальную сумму денег, необходимую для вычисления суммы данных `N` чисел.

### Входные данные

Первая строка входных данных содержит число `N` (`2 ≤ N ≤ 10^5`). Во второй строке заданы `N` натуральных чисел, каждое из которых не превосходит 10 000.

### Выходные данные

Определите, сколько денег потребуется для нахождения суммы этих `N` чисел. Результат должен быть выведен с двумя знаками после десятичной точки.

### Примеры

Входные данные:

```text
4
10 11 12 13
```

Выходные данные:

```text
4.60
```

Входные данные:

```text
2
1 1
```

Выходные данные:

```text
0.10
```

Идёт 2163 год. Мишу, который работает в отделении таможни при космодроме города Нью-Питер, вызвал в кабинет шеф.

- `a` — время прибытия груза;

## G. Задача №3407. Вычислительная ихтиология

Игорь работает младшим лаборантом в НИИ ихтиологии. Ему вверены `n` аквариумов, стоящих в ряд. В каждом из них живёт колония рыбок гуппи. Про каждую колонию заранее известна её численность.

В лабораторных условиях колония рыбок гуппи растёт по следующему правилу: достигнув популяции в 1000 рыбок, колония живёт в течение `1000 - f` секунд, после чего на свет появляется новая рыбка. От начального момента времени до рождения первой рыбки колония размера `f` также ждёт `1000 - f` секунд. Если популяция достигла 1000 или превысила это значение, следующая рыбка появляется через одну секунду.

Например, колония с начальным размером 996 будет размножаться следующим образом:

| Момент времени | Размер колонии | Время до очередной рыбки |
|---:|---:|---:|
| 0 | 996 | 4 |
| 4 | 997 | 3 |
| 7 | 998 | 2 |
| 9 | 999 | 1 |
| 10 | 1000 | 1 |
| 11 | 1001 | 1 |
| 12 | 1002 | 1 |

Появление на свет каждой новой рыбки Игорь должен фиксировать в специальном журнале. Запись делается мгновенно, но в момент рождения новой рыбки Игорь должен находиться рядом с соответствующим аквариумом.

На перемещение от одного аквариума к соседнему уходит одна секунда. В начальный момент времени Игорь стоит около первого аквариума.

Вычислите момент времени, когда родится первая рыбка, появление которой Игорь не сможет записать.

### Входные данные

В первой строке содержится целое число `n` — количество аквариумов. Каждая из следующих `n` строк содержит одно целое число `f` — начальную численность соответствующей колонии.

### Выходные данные

Выведите момент времени, когда родится первая рыбка, запись о рождении которой Игорь сделать не сможет.

### Пример

Входные данные:

```text
3
996
1
994
```

Выходные данные:

```text
7
```
